# THE SYSTEM 2.10.0

Achievement reveals, understanding quest proof, weekly preparation bosses and active equipment bonuses, built on the full 2.9.7 application.

- Earned levels, ranks, bosses and Ascension receive a confirmed reveal.
- Quest review accepts natural wording and typos, with useful follow-up questions and preserved input after a failure.
- Weekly bosses prepare actual breakfasts, lunches or outfits for the coming 5–7 days.
- Unlocked System gear can be equipped. Its listed bonus contributes to character power and effective attribute totals, with base and gear shown separately. Unequipping removes the bonus. Custom descriptions do not award stats.
- Music has accurate playback feedback, retry, class switching and persistent mute. Ordinary SFX never begin music.
- Assassin light mode displays the crimson class artwork.

See [feature and release details](docs/LIVING_SYSTEM.md) and [backend recovery](docs/BACKEND_RECOVERY.md). Frontend, Edge Functions and the delta migration form one release. Refresh an older open tab before submitting proof under the new receipt contract.

Validation: 99 automated tests, 390px/1440px feature browser checks, existing login/class/Archive regression checks and production builds. Real owner Google OAuth remains a separate account test.
